# MrCrayfish's Device Mod - Continued

**MrCrayfish's Device Mod - Continued** is an unofficial community continuation / experimental update of the original **MrCrayfish's Device Mod** for Minecraft 1.12.2.

This project exists because Minecraft 1.12.2 still has a huge legacy modding community, and I wanted to keep the Device Mod alive with small fixes, app improvements, and experimental new features.

> **1.12.2 never dies.**

## Important Notice

The original **MrCrayfish's Device Mod** was created by **MrCrayfish**.

I am **not** MrCrayfish, and this project is **not an official MrCrayfish mod**.  
This is an unofficial continuation / fork made by me.

Please do **not** report issues from this version to MrCrayfish.  
If you have crashes, bugs, missing textures, broken apps, or feature requests for this continued version, report them to me instead.

## What This Version Tries To Do

This continued version is focused on keeping the classic 1.12.2 Device Mod experience alive while adding small improvements and experimental content.

Current goals include:

*   Fixing broken or unfinished parts of the mod
*   Improving existing apps
*   Making hidden / unused apps usable where possible
*   Adding new features to existing apps
*   Improving the Emerald Bank app
*   Keeping compatibility with Minecraft Forge 1.12.2
*   Preserving the original nostalgic Device Mod feel

## Current Features / Changes

This version may include experimental changes such as:

*   Emerald Bank improvements
*   Account page UI
*   Balance display
*   App Store visibility changes
*   Bug fixes
*   Small UI improvements
*   Legacy compatibility fixes

Some features may still be unfinished or unstable.
